How to Install

Download the extension

Click the download button above. You will get a .zip file — no extraction needed.

Open Chrome Extensions page

In your Chrome address bar, type:

chrome://extensions

Turn on Developer mode using the toggle in the top-right corner.

Load the extension

Click "Load unpacked" in the top-left, then select the folder you extracted from the zip. The extension icon will appear in your toolbar.

Add your API key & resume

Click the extension icon, choose an AI provider (Groq is free and fast), paste your API key, and upload your resume. You only do this once.

Note: This extension is not yet on the Chrome Web Store. The method above loads it directly in your browser — it works exactly the same way and updates automatically when you re-download.
